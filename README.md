## 🏛️ Project Concept
STUDYVAULT is an intellectual knowledge sanctuary where Indian learners independently browse, access, annotate, and study peer-reviewed academic treatises at their own cognitive pace.

- **Not a coaching factory**: Zero hyperactive countdown timers, no aggressive sales calls, and no marketing feeds.
- **Tailored for the Indian Market**: Transparent INR pricing, UPI and RuPay architecture, and subjects covering Civil Services, Systems Engineering, Indian Macroeconomics, Jurisprudence, Higher Secondary Sciences, and Research Craft.

---

## ✨ Key Capabilities
1. **Cinematic Three.js Hero**: Interactive 3D floating hardcover monographs with realistic physical lighting, foil embossing, and floating gold dust particles.
2. **Interactive 3D Books**: Perspective 3D physical book inspection with textured spine depth and realistic page ridges.
3. **Command Palette (`Ctrl+K` / `Cmd+K`)**: Keyboard-driven fuzzy search across 1,200+ treatises, authors, and syllabi.
4. **Distraction-Free Reading Workspace**:
   - Optical serif typography (`Newsreader` & `Instrument Serif`)
   - Font scale adjustments (`A-`, `A`, `A+`)
   - Reading mode themes: **Parchment Day**, **Warm Sepia**, and **Academic Night**
   - Fullscreen Cognitive Focus mode
   - In-line Margin Notepad with local state persistence
5. **Transparent INR Membership**:
   - Monthly Pass (₹499/mo)
   - Academic Year Vault (₹3,999/yr — Save 33%)
   - Lifetime Scholar Patron (₹7,999)
   - Interactive UPI QR code and payment simulator with celebratory confetti.
6. **Scholar Dashboard**:
   - Study streak and focus hours analytics
   - Weekly cognitive distribution bar chart
   - In-progress reading resumes and bookmark management.

## 🛠️ Tech Stack
- **Framework**: React 19 + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Academic Design Tokens
- **3D & Graphics**: Three.js (WebGL) + Canvas Confetti
- **Icons**: Lucide React
- **Typography**: Instrument Serif, Newsreader, Plus Jakarta Sans, JetBrains Mono

---

## 🚀 Deployment on Vercel
1. Import this repository into [Vercel](https://vercel.com/new).
2. Framework preset will automatically detect **Vite**.
3. Build command: `npm run build`
4. Output directory: `dist`
5. Click **Deploy**!
